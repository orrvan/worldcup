## 核心原则与流程

- 回归足球本质：**近期事实数据 + 战术天然克制 + 个体球员近况**。
- **推演流程（顺序不可颠倒）**：步骤零 确认/预测首发阵容 → 维度一 近 5-10 场真实数据 → 五条修正层 → 输出结论。
- 步骤零：先查官方阵容；未公布则联网查询 + 预测各队最可能首发 XI，再基于阵容推演。
- 维度一（近 5-10 场大型赛事真实数据）为高权重，必须联网抓取真实赛果，用数据说话。
- 严禁一切盘口、让球、赔率等博彩数据污染推演。
